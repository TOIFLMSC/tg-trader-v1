# Тест-кейсы распознавания

Все кейсы выполняются в тестовом канале. Сейчас они проверяют только разбор сообщений: ордера и позиции не создаются. После каждого поста дождитесь карточки управляющего бота.

## 1. Рыночный вход и диапазон плеча

Опубликовать текст:

```text
BTCUSDT SHORT
Вхожу по рынку
Плечо 5–10x
Стоп 78900
Цели: 77100, 76900, 76700
```

Ожидается: `open`, BTCUSDT, SHORT, рыночный вход, диапазон 5–10x; расчетное плечо для будущего исполнения — 7x с округлением вниз; стоп и три цели.

## 2. Trigger-limit и отсутствующее плечо

Опубликовать текст:

```text
NEARUSDT LONG выше уровня 2.719
Входим при пробое уровня вверх.
```

Ожидается: `open`, NEARUSDT, LONG, trigger-limit с триггером 2.719. Плечо не выдумывается; требуется уточнение, предлагаемое значение — 1x.

## 3. Частичное закрытие по Reply

Ответить через Telegram Reply на пост из кейса 1:

```text
Фиксируем часть позиции
```

Ожидается: `close_partial`, связь с исходным BTC-постом, вопрос о проценте закрытия. Затем ещё одним Reply отправить `Закрываю 25%`: ожидается закрытие 25% оставшегося объёма.

## 4. Сопровождение без Reply по повторной карточке

Опубликовать карточку той же позиции, что и в исходном сигнале, с текстом:

```text
Снизим риск перед сном, закрою половину
```

Ожидается: `close_partial`, 50% оставшегося объёма и связь с исходным входом по сочетанию стороны, цены открытия и плеча. Похожее название другого токена не должно подменять тикер.

## 5. Отчёт о прибыли без торговой команды

Опубликовать карточку позиции с текстом:

```text
Уже +217%, отличный результат
```

Ожидается: информационный отчёт без `open`, `close_partial` или `close_full`. Процент доходности нельзя использовать как процент закрытия.

## 6. Стоп отдельным сообщением

Ответить через Reply на пост из кейса 2:

```text
Стоп ставим на 2.61
```

Ожидается: `set_stop`, NEARUSDT, уровень 2.61 и связь с исходным NEAR-постом.

## 7. Неопределённая команда

Ответить через Reply на любой открывающий сигнал:

```text
Стоп в безубыток, часть фиксируем
```

Ожидается: распознаны намерения перенести стоп и частично закрыть позицию, но без выдуманных цены безубытка и процента закрытия; оба значения должны быть запрошены у владельца.

## 8. Два сценария в одном посте

Опубликовать текст:

```text
AKEUSDT LONG от 0.02943, плечо 4x.
VTHOUSDT SHORT от 0.0006959, плечо 6x.
```

Ожидается: два независимых действия `open` с правильными тикерами, направлениями, ценами и плечами.

## Что записывать

Для каждого кейса сохранить номер поста и отметить: правильность тикера, действия, стороны, цены/триггера, плеча, стопов/целей, процента закрытия, связи с исходным постом и наличие лишних выдуманных параметров. Ошибочный разбор не исправлять новым постом до сохранения исходного результата.
